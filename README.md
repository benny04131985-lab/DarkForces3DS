# Dark Forces 3DS

Unofficial Nintendo 3DS port of **Star Wars: Dark Forces**, based on
**The Force Engine (TFE)**.

Current release: **v1.0.0**

## Highlights

- Native Nintendo 3DS homebrew build.
- True stereoscopic 3D gameplay on New Nintendo 3DS hardware.
- 3DS-native Circle Pad, C-nub and button controls.
- Lower-screen HUD presentation plus touch-capable frontend, pause menu and PDA.
- Native Dark Forces weapon, inventory/PDA, save/load and campaign behavior.
- Final weapon compositor keeps the first-person weapon flat/mono while the
  world remains stereoscopic.
- Release build uses the approved Dark Forces 3DS icon and metadata.
