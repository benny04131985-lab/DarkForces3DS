# Upstream and licensing

Dark Forces 3DS is an unofficial Nintendo 3DS port based on **The Force Engine
(TFE)** plus the 3DS-specific platform/render/input work in this source tree.

The public preparation process preserves the upstream license, COPYING and
NOTICE-style files already present in the TFE snapshot. Those original files
remain authoritative for the source components they cover; this helper does not
replace them with a newly invented license.

Commercial Star Wars: Dark Forces game data is not included and is not intended
to be redistributed with this project. Users supply data from their own legally
obtained copy.

Star Wars, Dark Forces and related names/assets belong to their respective
rights holders. This is an unofficial homebrew port.
