# Dark Forces 3DS v1.0.0

First public v1.0 release candidate/final release of the Nintendo 3DS port.

## Completed release systems

- The Force Engine Dark Forces campaign runtime on Nintendo 3DS
- Native 3DS renderer and New 3DS performance path
- True stereoscopic 3D gameplay
- Flat/mono first-person weapon composition over the stereo world
- Native Circle Pad movement and C-nub look/turn controls
- D-pad weapon cycling and four-item quick-equipment selector
- Native pause/menu and PDA access
- Lower-screen HUD plus frontend/pause/PDA touch interaction
- Save/load and normal Dark Forces campaign progression
- Approved 3DS icon and application metadata
- Logger-free release executable after extended hardware validation

## Distribution policy

The public source tree and GitHub Release exclude commercial Dark Forces game
data, development logs, crash dumps, build objects, backups and historical
patch-cannon artifacts.
