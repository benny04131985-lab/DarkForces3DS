# Dark Forces 3DS controls

This is the shipped v1.0.0 handheld mapping.

## Gameplay

- **Circle Pad** — move forward/back and strafe left/right
- **C-nub** — turn/look
- **R** — primary fire
- **L** — secondary fire
- **X** — jump
- **B** — crouch
- **A** — use / open / interact
- **START** — pause / Dark Forces menu
- **SELECT** — PDA / inventory / mission screen
- **D-Pad Up / Down** — previous / next weapon
- **D-Pad Left / Right** — cycle quick equipment
- **ZL** — use/toggle the selected quick equipment

Quick equipment cycles through:

1. Headlamp
2. Night Vision
3. Cleats
4. Gas Mask

The selected quick-equipment name is shown on the lower-screen HUD.

## Menus / frontend / PDA

- **C-nub** — move the cursor
- **R** — left-click / activate the highlighted cursor target
- **A** — confirm
- **D-Pad** — ordinary arrow navigation where the menu supports it
- **Touchscreen** — tap/click in the frontend, pause menu and PDA

Touch input is intentionally not used as a gameplay look/fire surface. Normal
play uses the physical controls above.
